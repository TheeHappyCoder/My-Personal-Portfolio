# MarkOS Arcade third-party notices

MarkOS Arcade contains local adaptations of these open-source browser games:

- Cache Overflow: adapted from 2048 by Gabriele Cirulli, https://github.com/gabrielecirulli/2048
- Bug Sweeper: adapted from Minesweeper by Ania Kubow, https://github.com/kubowania/minesweeper
- Break Production: adapted from 2D Breakout Game by Leonardo Schneider, https://github.com/CapnSane/2D-breakout-game

Original names, presentation, styling, and integration have been replaced for MarkOS. No original image, font, or audio assets are included.
